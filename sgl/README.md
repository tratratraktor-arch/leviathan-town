# SunGuard Leviathan

Своя пиксельная игра клана SGL, написанная с нуля, без кода Pony Town.
Пока в ней есть редактор персонажа и одна локация «Площадь Левиафана».

## Как запустить

Ничего ставить не нужно: откройте `index.html` в браузере (двойной щелчок по файлу).
Игра целиком работает в браузере, сервер пока не нужен.

## Что есть

- **Редактор персонажа.** Имя, фракция, цвет кожи, волос и глаз, причёска.
  При выборе фракции персонаж сам надевает её одежду:
  - **Порождённые**: рога, рваное тёмное платье с бусами, полосатые гетры;
  - **Зиккурат**: шляпа с пером, тёмный двубортный камзол с розовыми пуговицами, штаны с заплатками, сапоги;
  - **Мракоборцы**: светлый плащ с капюшоном, длинное светлое одеяние, перчатки.
  Персонаж запоминается в браузере.
- **Локация.** Площадь с фонтаном, зиккурат, пруд, лес по краям.
  Ходить стрелками или WASD, Shift бегом, или кликнуть мышью (пальцем) туда, куда идти.

## Файлы

- `index.html` страница игры: что где лежит на экране.
- `style.css` внешний вид кнопок и окон.
- `js/sprite.js` рисует персонажа по точкам: тело, лицо, волосы и одежду трёх фракций.
- `js/editor.js` редактор персонажа.
- `js/world.js` строит локацию: клетки земли и предметы (деревья, фонтан, зиккурат).
- `js/game.js` ходьба, камера и рисование каждого кадра.
- `js/main.js` переключает редактор и игру.

Персонаж это сетка 28×46 точек. Чтобы добавить новую вещь, в `js/sprite.js`
дописывают, какие точки каким цветом закрасить.
